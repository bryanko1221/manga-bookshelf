# 我的漫畫書櫃 V2.1 優化穩定版

本版以 V2.1 為重新起點，不沿用 V2.4.x 的資料遷移邏輯，避免舊版本造成漫畫消失。

核心書單固定 19 部：
1. 某天成為魔神
2. 我獨自滿級新手
3. 無限升級印武林
4. 我獨自升級
5. 與神一同升級
6. 絕對劍士
7. 殺手巴德洛
8. 拳王歸來
9. 現實闖關
10. 公爵家的重生暗殺者
11. 魔道轉生記
12. 至活今天的輪迴騎士
13. 絕對回歸
14. 輪迴天魔
15. 天才策士
16. 重生傭兵王的復仇
17. 殘命天才生存法
18. 裝備我最強
19. 劍尊歸來

功能：
- 19 部核心書單直接內建，不依賴瀏覽器舊資料才能顯示。
- 搜尋
- 分類
- 收藏
- 最近閱讀
- 深色模式
- 手機版兩欄
- 封面網址資料獨立保存
- 原漫畫網址固定在程式內，避免編輯畫面空白造成資料遺失。

資料設計：
- 漫畫基本資料（名稱、網址、分類）＝固定核心資料。
- 使用者資料（收藏、最近閱讀、封面、深色模式）＝另外保存。
- 因此更新網站程式時，不會因 localStorage 舊資料格式不同而把 19 部清空。
